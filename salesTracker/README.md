# Sales Tracker

A React-based Sales Tracker application that helps users manage products, track sales revenue, and monitor monthly performance through an interactive dashboard. The application provides a simple way to organize sales records and analyze business growth.

## Features

- Add Products
- Track Sales Revenue
- Monthly Reports
- Dashboard Statistics
- Search Products
- Revenue Summary
- Local Storage Support
- Responsive User Interface

## Tech Stack

- React
- JavaScript (ES6)
- CSS
- Vite
- Local Storage

## Installation

Clone the repository:

```bash
git clone https://github.com/vinayak833/SalesTracker.git
```

Navigate to the project directory:

```bash
cd SalesTracker
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

## Usage

1. Add products with sales information.
2. View product records.
3. Track total revenue generated.
4. Analyze monthly sales reports.
